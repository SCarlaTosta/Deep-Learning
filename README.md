## Experiments

### y = x²

One of my experiments was training a neural network to learn the function:

```text
y = x²
```

I also tested the model with values between the training points and outside the training range to see how well it generalizes and extrapolates.

### Optimizers

I'm currently trying to understand how each one affects training rather than just using them as black boxes.
